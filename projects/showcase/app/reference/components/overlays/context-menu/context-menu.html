Key Does
ArrowDown, ArrowUp Next or previous item, wrapping. With focus still outside the menu: its first or last item.
Home, End First or last item.
Type a letter Next item of that menu that starts with what you typed; the same letter again cycles.
ArrowRight Opens the item's submenu, focus on its first item.
ArrowLeft Closes the submenu, focus back on its item.
Enter, Space Chooses the item, or opens its submenu.
Escape Closes one level: a submenu, then the menu. Focus returns to where it was if it had moved in.
Tab Closes the menu and moves on from where it was opened.
