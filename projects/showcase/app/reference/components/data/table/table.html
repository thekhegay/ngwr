  • set(value) keeps a value while the reader types. Enter, Tab and a click outside commit it. commit(value) ends the edit at once, cancel() drops it.
  • cellEdit carries row, key, value and previous. Validate there: a value you do not write is refused. An unchanged value emits nothing.
  • editable: false on a column keeps it read-only. The editable input vetoes single cells: here an archived product keeps its price.
  • One cell edits at a time. A sort, a hidden column or a removed row ends the edit without a commit.
  • With an edit template the table announces a grid and its data cells take focus.
  • Name the editor: the cell has no label for it, so set ariaLabel.
  • The rows take the keyboard: Tab reaches one row, Up and Down move, Right opens a row or steps into it, Left closes it or climbs to the parent, Home and End jump. Enter and Space select the row when rowSelection is set. Tab moves on into the row's own controls. Since v15.
