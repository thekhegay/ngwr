Event Signal
set, update Stores, then takes the value. An equal value is a no-op.
store.set(), remove(), clear() Follows, back to the default on removal.
Another tab writes or removes Follows through the storage event.
Quota exceeded Logged, never thrown. The signal keeps the value for this tab.
Server Holds the default, no listener.
