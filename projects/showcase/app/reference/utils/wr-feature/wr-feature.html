Argument What it is
kind The feature's name. In dev mode provideWr() throws when it gets the same kind twice, so pick one no other feature uses.
providers What the feature registers. provideWr() flattens them into its own providers.
  • Give the token a root default, so the setting is optional.
  • Annotate the return type as WrFeature<'kind'>. Do not read the object's members: they are private.
