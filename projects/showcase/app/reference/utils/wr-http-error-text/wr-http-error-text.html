overrides[status] The screen names the status. A string, or a function of the error.
The response body Only with serverMessage: true: error.error.message, or a body that is a plain string. An empty one, or an HTML page from a proxy, is skipped.
httpError.<status> The catalog has the status: 400, 401, 403, 404, 409, 413, 422, 429 and 503.
httpError.4xx, httpError.5xx Any other status of that class. Both take {{status}}.
httpError.network Status 0: offline, CORS, a dropped connection.
httpError.unknown Not an HTTP error, or a status outside 4xx and 5xx.

The texts ship in every ngwr catalog, so register yours with provideWrI18nBaseCatalogs(). With none registered the text is English.
