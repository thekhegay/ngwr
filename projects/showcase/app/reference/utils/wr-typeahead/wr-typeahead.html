Typed Result
One letter The next row after the current one that starts with it, wrapping past the end.
The same letter again The next row that starts with it, so the letter cycles.
More letters The row that starts with the whole run. The current row stays while it still matches.
A pause of resetMs The next key starts a new run.
Space Joins a run that has started. As the first key it is left to you.
Ctrl, Meta or Alt, an IME key, a key in a text field Left to you: handleKey returns null.
