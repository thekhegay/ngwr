Type and page, then watch the address bar. Back and Forward move both signals. q replaces the history entry, page pushes one.

When What happens
The parameter is absent Reads as default. A repeated one reads its first value.
A write of default Removes the parameter. Already absent: no navigation.
Several writes in one task One navigation, across every signal. Other parameters and the fragment survive.
replaceUrl differs within one task The navigation pushes. A replaced entry is lost; a pushed one is one more Back.
A navigation is in flight The write waits, then lands on the address it produced.
Its navigation is cancelled or fails The signal reads the address again. A lost write is never kept.
The injection context is destroyed Following stops. A write already made is navigated, unless it was waiting for the navigation that destroyed it.
On the server Reads from the router. A write moves the signal only; prerender and hydration navigate nothing.
