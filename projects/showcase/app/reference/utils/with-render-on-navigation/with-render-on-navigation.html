The feature ticks right after NavigationEnd, before the task ends. The page is bound before the first paint. Angular schedules the tick as a macrotask on purpose, see angular/angular#57528.

Case Why
Your app uses zones Change detection already runs in the same task.
Routed pages have no transitioning bindings Nothing fades, so nothing shows.
Only ngwr components flicker They carry static host classes since v16.1. The feature covers your own bindings.
