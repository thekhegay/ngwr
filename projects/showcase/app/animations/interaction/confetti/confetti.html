Part Behaviour
Screen readers The canvas is aria-hidden, holds no content and takes no pointer.
Reduced motion Under prefers-reduced-motion: reduce a burst does nothing, and a preference that flips mid-burst clears the canvas at once. Under forced-colors: active nothing is drawn.
Hidden document A hidden tab pauses the loop; a visible one resumes it where it stopped.
Server A burst on the server does nothing: the canvas exists only in the browser.
