Part Behaviour
Keyboard Focus inside the card, with no pointer over it, is the stylesheet's own :focus-within rule: the same light at the centre, at half strength, so a keyboard user gets the same hint. A pointer inside wins.
Screen readers Nothing is added to the card: the light is two pseudo-elements, and the host keeps its own name.
Touch A touch pointer is ignored: it has no hover, and a tap would leave the light on.
Reduced motion The light following the pointer is a pointer response, not motion, so it stays; only the fade in and out goes. Under forced-colors: active nothing listens, since the stylesheet paints nothing.
Server Nothing runs: the listeners are added after the first render, in the browser only.
