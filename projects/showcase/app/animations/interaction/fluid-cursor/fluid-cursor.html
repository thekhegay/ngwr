Part Behaviour
Screen readers Decorative: the host is aria-hidden, holds no text, takes no pointer and is never focusable. The listeners on the parent are passive and stop nothing, so every control over the ink behaves as before.
Touch A finger draws like a mouse, and is never stopped from scrolling: nothing is prevented and touch-action is left alone, so a scroll that starts over the region scrolls.
Reduced motion Under prefers-reduced-motion: reduce nothing is drawn and no context is made; a trail caught moving when it is turned on is cleared. Under forced-colors: active nothing is drawn either.
No WebGL Without WebGL2, or WebGL1 with half-float render targets, nothing is drawn; a lost context is let go and rebuilt when the browser restores it.
Server The empty canvas is rendered, absolutely positioned, so the browser's first draw shifts no layout.
