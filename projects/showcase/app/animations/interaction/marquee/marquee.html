Part Behaviour
Screen readers The second copy is aria-hidden and inert, so the list is heard once, as a list of links named by label, and tabbed once.
Keyboard A link that takes focus stops the row: the viewport scrolls natively and the link is brought into view, so what has focus is what can be seen. Leaving the belt resumes the loop from the start of the row.
Pausing The row stops under the pointer, while focus is in it, off screen and while the document is hidden. With pausable it also stops on the pause button, and that pause stays until the button is pressed again. A marquee that runs on for more than five seconds needs a way to stop it (WCAG 2.2.2): pausable provides one, hover and focus pause alone do not.
Reduced motion Under prefers-reduced-motion: reduce the row never moves: one copy, scrollable, under the same fade, with no pause button even with pausable.
Server The one copy is rendered as a still row; the loop starts from the same picture, so nothing shifts.
RTL The belt travels toward the inline start, so under RTL the row runs the other way.
