Part Behaviour
Screen readers While the pieces play they are aria-hidden, and a visually hidden copy of the text stands beside them, so the headline is announced once. At rest the host holds the plain text.
Reduced motion Under prefers-reduced-motion: reduce the stylesheet plays nothing and the host swaps to the plain text at once. The demos on this page follow the same setting.
Server and no script The pieces are in the server HTML and the animation is CSS, so it starts at first paint and runs on through hydration. Without script the pieces simply end fully visible.
Wrapping The letters of one word sit in a no-wrap wrapper and the spaces between words stay real text, so the lines break where plain text would.
