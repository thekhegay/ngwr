Screen readers The box is aria-hidden and a visually hidden copy beside it carries every line once, so a reader hears the text, never a letter at a time. The copy is out of the selection, so a copy of the line gives the typed text.
Reduced motion Under prefers-reduced-motion: reduce the first line stands whole with no caret. The demos on this page follow the same setting.
Server The server renders the first line whole, readable without script, and that is what a still page shows, so nothing swaps at hydration. Write the first line as the one that stands alone.
Layout Every line is laid out in the same cell, the ones not on show invisible, so the box takes the longest line's size from the first paint and a centred or wrapped line never jitters.
