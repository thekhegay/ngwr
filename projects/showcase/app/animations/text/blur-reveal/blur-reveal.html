The checks behind ngwr.

Each word waits for the one before it.

Part Behaviour
Screen readers While the pieces play they are aria-hidden, and a visually hidden copy of the text stands beside them, so the sentence is announced once and never letter by letter. At rest the element holds its original text nodes.
Reduced motion Under prefers-reduced-motion: reduce nothing is split and nothing moves: the text is shown as authored. The demos on this page follow the same setting.
Server The server renders the plain text. The split happens in the browser, after the first render, and only where IntersectionObserver exists.
Selection and search Spaces between pieces stay real text, so the words wrap where they did, and find-in-page and copy work once the reveal has ended.
