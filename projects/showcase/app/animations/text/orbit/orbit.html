Part Behaviour
Screen readers The <svg> is role="img" named by label, or by the text with its trailing separator cut, and the ring's glyphs are aria-hidden, so the label is heard once. The slot's content keeps its own semantics.
Selection The ring is decorative and not selectable: a drag across the page does not pick up the legend.
Reduced motion Under prefers-reduced-motion: reduce the ring sits still, fully drawn. The demos on this page follow the same setting.
Server The ring is static markup, so the server renders it finished and even. The turn starts in the browser, only while the ring is on screen and the page is visible, and only where IntersectionObserver exists.
