Part Behaviour
Screen readers While the slots play they are aria-hidden, and a visually hidden copy of the text stands beside them, so the text is announced once and the noise never. At rest the element holds its original text nodes.
Reduced motion Under prefers-reduced-motion: reduce nothing plays, in either trigger mode: the text is shown as authored. The demos on this page follow the same setting.
Keyboard In hover mode focus plays it too, read on the closest focusable ancestor, so a label inside a button or a link behaves the same for a pointer and for Tab.
Layout The real character stays in its slot, hidden, and the glyph is painted over it out of flow, so the line keeps its width and nothing around it moves.
Server The server renders the plain text. The slots are created in the browser, after the first render, and in view mode only where IntersectionObserver exists.
