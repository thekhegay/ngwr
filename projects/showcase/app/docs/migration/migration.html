  • Put withDensity(), withToast() and withTheme() in the app providers. A lazy route never reads them.

  • A var() at a removed token drops its whole declaration, with no error. Search for every name above.
  • Without strictTemplates, a removed color value renders neutral, with no error.
  • A leftover [data-theme] selector compiles and matches nothing.
  • To stay light, add :root { color-scheme: light; } after @use 'ngwr/theme'.
