Write them below the theme line: animations and typography-utilities load the token layer too.

A dev build warns once in the console when a component renders without its sheet, naming the @use line to add and the ng g ngwr:component-style command that adds it.

$layer puts every reset rule in that layer. The layer starts where the reset is emitted, so it ranks below unlayered styles and every layer declared after it.

An app that loads a sheet lazily inside a layer, so its copy of the theme loses to the brand, needs this. Unlayered, the reset beat that layer and took the fills off calendar events and the borders off selects.

The reset no longer brings the theme with it: it only reads the tokens. Keep @use 'ngwr/theme' in your styles, or headings fall to the body size.
