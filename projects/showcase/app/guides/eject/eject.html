Never import the copy and the package's component into the same template: both match the same selector. To use both, rename the selector and the .wr-* classes in the copy.

A few components read a file the package exposes under no path. The command copies the rest and prints each such line as a warning, with the file and the line to fix.

Point the imports back at ngwr/button and restore @use 'ngwr/button'; in the stylesheet. Updates reach the component again.
