updateOn: 'blur' or 'submit' is ignored: the value and its errors update on every edit. Debounce expensive checks in an async validator.
A write with {{ '{' }} emitEvent: false {{ '}' }} does not repaint the control. Call markForCheck() after the write.
Validators.required does not mark the field as required. Add required to <wr-form-field>.
Reactive forms have no read-only state. Bind [readonly] on the control.
<wr-select> matches values with ===, so a copied object shows the placeholder. Bind a primitive key, such as cat.id.
A value outside [min] / [max] stays in the model; the control never corrects it. Use Validators.min / max to flag it.
<wr-slider> ignores null, so reset() leaves the thumb where it was. Reset it to a number.
