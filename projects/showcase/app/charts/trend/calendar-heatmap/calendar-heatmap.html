Part Behaviour
Grid One role="img", named by ariaLabel. The days announce nothing.
Values Not in text unless dataTable is on. Without it, say what the year shows in ariaLabel.
Keyboard No tab stop while the year fits. While it scrolls, the grid is one tab stop and the arrow keys scroll it.
Tooltip Pointer only. The table carries the same counts.
Weekday names Three of seven, since seven do not fit. The table names every day.
Lowest level A tint of the surface. Every day has a faint edge, so it still reads on a dark page.
Scale key Hidden from screen readers, like an axis. The table has the counts.
States The empty and loading messages are a role="status"; a failed load is a role="alert".
Forced colours The days keep their colours.
