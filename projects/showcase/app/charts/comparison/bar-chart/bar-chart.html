The palette is not the status colours: a second series is not a success. Series take it in order. Every colour holds 3:1 against the surface in both schemes, and neighbours differ in lightness as well as in hue. The sequential scale steps the first colour toward the surface, so it turns over with the scheme.

Part Behaviour
Plot A role="group", named by ariaLabel.
Bars Each bar is a role="img" named by its label and value. With series, each category is a named group and each bar is named by its series. With stacked, each printed total is a role="img" named “Total: 20”.
Lines Each line is a role="group" named by the line, after the bars. Each point is a role="img" named by its category and value.
Series Neighbouring palette colours differ in lightness as well as in hue, every bar is named, and the tooltip and the data table name each series. Each line has its own dash and marker.
States The empty and loading messages are a role="status"; a failed load is a role="alert".
Keyboard No tab stop, unless toggleableLegend makes the legend rows buttons.
