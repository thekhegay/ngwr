Part Behaviour
Cells One role="img", named by ariaLabel. The cells announce nothing.
Value Colour is the only thing that encodes it, as in every heatmap. showValues and dataTable give it in text.
Equal values One level, the lowest, and one swatch in the legend: an all-zero matrix is a faint tint, not the peak.
Empty cell Hatched and outlined, so it differs from the lowest level without colour.
Row and column names Real text. Column names that do not fit are thinned to every n-th, and the rest stay readable to a screen reader. A long row name is cut with an ellipsis. The tooltip and the table carry every name whole.
Legend Hidden from screen readers, like an axis. The table has the figures.
Keyboard No tab stop. The tooltip is pointer only.
RTL The matrix mirrors, like a table: the row names move to the right.
